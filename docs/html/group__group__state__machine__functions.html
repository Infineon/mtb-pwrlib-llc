◆ STATE_MACHINE_Init()

void STATE_MACHINE_Init ( void )

Initialize the state machine module.

Populates the state table with Entry/Exit/RunISR0/RunISR1 callbacks for each STATE_ID_t, initializes the function-execution handler, and enters Init_State. On first entry into Init_State, hardware interface and parameters are initialized and all control sub-modules are reset.

Note
The extra ISR callbacks (STATE_ADD_CALLBACK_t) are set to empty functions and must be reassigned by the application if needed.
After the boot timer expires, the state machine transitions to Soft_Start_State automatically if auto-start is enabled (default). If auto-start is disabled, the state machine remains in Init_State until an external enable command is received.

◆ STATE_MACHINE_RunISR0()

void STATE_MACHINE_RunISR0 ( void )

Execute the fast ISR task.

Runs common fast-rate processing (sensor interface, fault protection, and filters when not in Init_State), then invokes the current state's RunISR0 handler and the extra fast callback. This function is placed in RAM for deterministic execution time.

Note
Must be called periodically at the fast ISR rate.

◆ STATE_MACHINE_RunISR1()

void STATE_MACHINE_RunISR1 ( void )

Execute the slow ISR task.

Runs common slow-rate processing (sensor interface, fault protection, function-execution handler), then invokes the current state's RunISR1 handler and the extra slow callback. After execution, evaluates state transition conditions and performs Entry/Exit callbacks on state change.

Note
Must be called periodically at the slow ISR rate. State transitions only occur at the end of this function.

◆ STATE_MACHINE_ResetAllModules()

void STATE_MACHINE_ResetAllModules ( void )

Reset all control sub-modules to their initial state.

Re-initializes and resets sensor interface, fault protection, output voltage control, system identification, and filters.
